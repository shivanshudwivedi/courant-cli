# Courant CLI (superseded)

This repository holds the installer and the v0.1.0 build (17 August 2026) of an early Courant
prototype that diagnosed and repaired failing OpenFOAM runs. That direction is retired, and this
build is no longer developed or supported.

**Courant is now physics acceptance testing for AI-produced simulation:** a read-only, deterministic
check between an AI agent's simulation and the engineer who signs it. It never edits a case. The
current verifier has not been publicly released, and this installer does not install it.
